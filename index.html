雪球菜单

背包里的雪球是随身菜单：「我的账户」里有你的玩家 ID，还能给别人转服务器币、发起互传、传送去各个区域。身上没带雪球的时候，输入 /trigger menu 一样能打开。

玩家 ID

Tab 列表里名字旁边的数字就是你的 ID，和「我的账户」里显示的是同一个。授权地皮、邀请进公会、转让领地，填的都是这个数字。

    地皮、公会和领地

    想在天上盖房子，先买一块地皮；朋友多了就建公会，换一块大得多的公会地皮；主城和大型建筑由管理员圈成领地保护起来。

    地皮

    在地皮大厅点「购买地皮」，300。每人一块，32×32，中间 30×30 是草地，建在 y=250 的天上。只有主人和被授权的人能建造，别人来了只能参观。

    • 最多授权 4 个人一起建：[授权身边玩家] 或 [按ID授权]。
    • [上锁/解锁] 不让外人进；[访客交互开关] 默认禁止，访客开不了箱子和门；[清怪开关] 默认打开。
    • 不想要了可以转让：[转让给身边玩家] 或 [按ID转让]。
    • 菜单：/trigger plot

    公会

    创建公会 3000，创建时手里拿一个用铁砧改过名的物品，公会就叫这个名字。最多 20 人，分会长、副会长和成员。

    • 成员可以把服务器币捐进公会资金。
    • 公会地皮 200×200，花 5000 公会资金购买，每个公会一块，本公会成员都能建造。
    • 会长和副会长可以给公会地皮上锁、关访客交互、开关清怪。
    • 菜单：/trigger gh

    领地

    领地是管理员圈出来的保护区，可以划给个人或者公会。主世界、下界、末地都能圈。

    • 上锁后，没权限的人走进来会被移到边界外。
    • 主人可以在领地里 [设置传送点]；打开 [他人传送开关] 后，别人也能传送过来。
    • [回我的领地] 一键回家，[开放传送的领地] 列出所有能去的地方。
    • 菜单：/trigger ld

    新手问答

    进不去服务器怎么办？

    先确认游戏是 Java 版 26.3，地址填 frp-fan.com:29426，冒号和后面的端口号都要带上。还是进不去，就到 QQ 群 1128633920 问一声。

    我的玩家 ID 在哪看？

    Tab 列表和雪球菜单的「我的账户」里都有。授权地皮、邀请进公会、转让领地，填的都是这个数字。

    第一笔服务器币怎么赚最快？

    去小游戏大厅跑一趟天空跑酷，到终点就有 30 币。人多的时候排 TNT Run 或色盲派对，满 2 人就能开局。

    加入小游戏提示背包不为空？

    盔甲栏和副手也要空着，只有菜单雪球可以留。先把东西存进箱子再去排队。

    从小游戏出来一直是冒险模式？

    小游戏大厅范围里会自动切成冒险模式，走出大厅就会变回生存。

    别人能动我地皮上的东西吗？

    不能。没授权的人只能参观，访客交互默认禁止，开不了箱子、门和按钮。想让朋友一起建，在 /trigger plot 里授权他，最多 4 个人。

    公会怎么建？

    攒够 3000 服务器币，手里拿一个用铁砧改过名的物品，打开 /trigger gh 点创建，公会就叫这个名字；不拿的话叫「你的名字的公会」。

    地皮不想要了怎么办？

    每人只能有一块地皮。可以在 /trigger plot 里转让给别人：[转让给身边玩家] 或 [按ID转让]。
